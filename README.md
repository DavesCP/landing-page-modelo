# Whitepace: landing page

Landing page de um software de gerenciamento de projetos, feita do zero em **HTML, CSS e JavaScript puros** a partir do layout de referência Whitepace.

🔗 **No ar:** [davescp.github.io/landing-page-modelo](https://davescp.github.io/landing-page-modelo/)

![Seção inicial da landing page Whitepace](docs/screenshot.png)

## Destaques

- Sem frameworks: HTML semântico, CSS e JavaScript puros
- Layout responsivo com media queries
- Seções de hero, recursos, patrocinadores, depoimentos, preços e chamada para ação
- Publicação automática no GitHub Pages com GitHub Actions

---

**English:** A landing page for a project-management SaaS, built from scratch in plain HTML, CSS and JavaScript from the Whitepace reference layout. It is responsive and deployed to GitHub Pages with GitHub Actions.
